# 初選落選名單在開始投票時定案，不隨退房改變

2026-10-03 需求訪談新增「初選」：候選多於成員數三倍時，全員嚴格過半可進入初選，每人圈選 3 到 5 家，無人圈選的候選不進轉盤。需求方裁定：初選期間退房者的圈選立即失效，但房主一開始投票，落選名單即定案，之後任何人退房都不讓落選店復活、也不讓入圍店消失。這是 ADR-0007「退出者意見即刻停止約束盤面、重算以現任成員為準」的刻意例外。

## Considered options

- 開始投票時定案 — 已選擇；轉盤名單在投票期間穩定，成員已對入圍店投下的贊成票與否決不會因別人離席而落空。
- 每次重算以現任成員的圈選重新判定 — 未採用；與 ADR-0007 一致，但投票中有人退房會讓只有他圈的店連同其他人已投的票一起從轉盤消失。

## Consequences

- 落選是與本批排除同性質的持久排除：一般重算與退房不得讓它復活，重新搜尋（修改條件、改地點、候選耗盡回準備）後重置。
- 初選期間（開始投票前）仍依 ADR-0007：退房者的圈選與初選表決意願即刻作廢，「全員圈滿 3 家」與過半門檻以現任成員重算。
- 房主取消初選回到候選出爐時，圈選與初選表決意願都作廢，不留下落選。
