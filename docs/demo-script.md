# Demo script（雙瀏覽器，約 3 分鐘）

1. 瀏覽器 A：註冊「小明」→ 選出發點、用餐時間留「馬上出發」→ 建立房間 → 唸出邀請碼
2. 瀏覽器 B（無痕）：註冊「小華」→ 輸入邀請碼加入
3. A：預算 800、偏好日式+火鍋、步行、800m（A 是房主，免按「我準備好了」）
4. B：預算 400、偏好台式、**素食**、步行、800m → 按「我準備好了」（條件即凍結，再按一次解凍）
   （重點：B 的素食會硬排除火鍋/燒肉類，B 的 400 預算會排除高價位）
5. （選）A 在房間設定示範兩個房間層旋鈕——探索檔位（熟悉／平均／探索新店）與
   「菜系過濾」開關。兩者都只在搜尋前可調，示範完把菜系過濾關掉再繼續
6. A 按「開始搜尋餐廳」→ 兩邊同時出現候選清單
7. 指出畫面重點：每家的機率 %、綠色加權 chips、紅色降權 chips、
   展開「被排除的 N 家」唸排除原因（例：價位超過預算上限）
8. A 按「開始投票」→ A、B 可對候選按「贊成」或「否決」；每人否決額度 2，可再次點擊收回
9. A 按「啟動轉盤」→ 兩邊同步旋轉、停在同一家
10. 結果卡 → 點「用 Google Maps 導航」→ 開啟 Maps 且交通方式正確
11. （選）結果卡下方點星補餐後評分 → 按房間頁的「足跡」看時間軸、統計與評分走勢
12. （選）打開 Supabase Studio 看 draws.seed 與機率快照 — 抽選留有紀錄

**demo 期間不要按「回首頁」**：回首頁＝離席（ADR-0007）。房間頁與足跡頁的「回首頁」
都會先跳「離開房間？」確認框——房間頁按「取消」留在原地；足跡頁除了「取消」還多一顆
「回到房間」直接回去（只在單一房籍時出現）。但只要按下確認就真的退出房間，最後一人退房
整間房會被刪掉，demo 得從頭來。第 11 步從足跡頁回房走「回到房間」或瀏覽器上一頁。

備註：mock 營業時間對照真實時鐘。深夜展示時素食組合仍可中（復興清粥小菜 24h）；
任何時段皆可用的保底組合：日式 + 預算 800（一蘭拉麵 24h）。
